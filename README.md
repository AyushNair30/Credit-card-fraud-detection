## Dataset

This project uses the Credit Card Transactions Fraud Detection Dataset from Kaggle.

**Dataset source:** [Credit Card Transactions Fraud Detection Dataset](https://www.kaggle.com/datasets/kartik2112/fraud-detection)

### Files required

Download the following files from the Kaggle dataset page:

- `fraudTrain.csv`
- `fraudTest.csv`

### Setup instructions

1. Open the Kaggle dataset link above.
2. Sign in to Kaggle if prompted.
3. Download the dataset.
4. Extract the downloaded files.
5. Place both CSV files in the `data/raw/` directory.

The expected directory structure is:

```text
credit-card-fraud-detection/
└── data/
    └── raw/
        ├── fraudTrain.csv
        └── fraudTest.csv
```

**Note:** The dataset files are not included in this GitHub repository. Download them from Kaggle before running the notebooks.
